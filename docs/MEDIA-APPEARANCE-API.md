# 动态媒体、合并身份、外观与 API 验收

日期：2026-10-15。当前 Web 缓存 **v28**，业务 schema **v4**，设备外观 **v2**，应用包版本仍为 `1.0.0`。

本轮保持用户认可的固定自然高度布局、本地优先和本地背景选择，不恢复 GridStack 编辑、不重写应用。验证使用独立临时浏览器 profile 与合成资料，没有清除真实站点数据、读取真实 Key 发请求、上传个人备份或媒体、提交 / 推送、生成 dist、安装原生 SDK 或编译 exe / APK。

## 1. 图标、文字与实际动作

| 入口 | 当前约定 |
|---|---|
| 专注 | 桌面、手机及全部功能入口统一计时器图标与“专注”，不再用书本图标代表计时 |
| 设置 | 使用齿轮与“设置”；头像不再兼作设置按钮，避免品牌 / 个人身份 / 设置三种语义混用 |
| 计划排序 | 使用上下排序箭头，不冒用筛选图标；显示当前排序方式，title / aria-label 说明点击后的变化 |
| 提醒声音 | 开启 / 关闭分别显示有声 / 静音图标；文字、title、aria-label、aria-pressed 与保存状态一致 |
| 添加提醒 | 首页与日历入口都定位同一定时提醒表单并聚焦名称，不再一个仅跳页、另一个才进入表单 |

真实鼠标 / 键盘检查覆盖上述入口、排序结果、声音持久状态、手机 44px 主要操作区和提醒表单焦点。

## 2. 只保留一处名称与个人形象

设置页合并为 **“工作台与个人形象”**：

- 主区域：工作台名称、共享头像 / 标识、统一预览以及一组“保存名称与形象 / 取消修改”。
- 可选区域：问候称呼、图片缺失时的文字 / 表情、默认图标 / 共享头像 / 独立 Logo 来源及独立 Logo 上传。
- 选择共享图片会在同一草稿立即进入品牌预览，不必先保存另一张卡。保存一次原子提交名称与形象。
- 图片优先、文字回退；移除图片保留文字。切换标识来源不删除另一个已保存素材，“使用默认图标”也不重置名称。
- 旧称呼、个人头像和独立 Logo 字段保留；合并界面不等于合并或删除旧数据。
- 图片处理期间不能保存。取消会废弃过期异步上传，清理的仅是当前草稿新建、未提交的本地资产；保存失败保留草稿供重试。
- 逐字段同步未修改的身份字段，保留当前本地编辑；独立 Logo 不会被个人头像变更静默覆盖。
- 浏览器标签页使用静态图标。已安装 PWA 的桌面名称 / 图标不会即时随之改变。

## 3. 真正保留动画，而不只是接受扩展名

### 支持范围与限制

| 用途 | 格式 / 限制 |
|---|---|
| 静态头像 / Logo / 背景 | PNG、JPEG、WebP，保留原有 10 MiB 输入与压缩路径；最多 5000 万像素，最长边不超过 32768。头像编码为小尺寸安全预览，背景最长边压至 1920px |
| 动态头像 / Logo | GIF、动画 WebP，最多 2 MiB、最长边 1024px、300 帧 |
| 动态图片壁纸 | GIF、动画 WebP，最多 8 MiB、最长边 4096px、200 帧 |
| 动画通用预算 | 累计帧画布像素不超过 1 亿；先扫描容器边界 / 尺寸 / 帧数，再交给浏览器解码 |
| 视频壁纸 | 本地 MP4 / WebM，最多 30 MiB、最长边 3840px、有限时长大于 0 且不超过 120 秒；静音、循环、行内播放，受实际浏览器 codec 支持限制 |
| 本地字体 | WOFF2，最多 5 MiB；签名、头部长度与 FontFace 解码都通过才预览 |

明确拒绝 APNG、SVG、远程媒体 URL、损坏 / 超限素材，不把 APNG 静默压成一帧。Windows 未提供 WOFF2 MIME 时，仅对 `.woff2` 文件允许受约束的 MIME 回退，二进制和字体解码仍必须通过。单帧 GIF 会作为安全静态图处理。

### 展示与资源生命周期

- 动态 GIF / WebP 原始 Blob 存于 IndexedDB `lime-local-assets`；不把大动画 base64 塞进 localStorage。视频和自定义字体使用同一本地资产库。
- 暂停 GIF / WebP 时切换为静态封面，不用 CSS `animation-play-state` 假装暂停图片动画。
- 动态效果可跟随系统 / 播放 / 暂停，顶部可快速切换；系统减少动态偏好与页面隐藏时使用封面 / 暂停视频。
- 视频被浏览器阻止播放时显示封面与提示，可再次选择播放。正常 `pause()` / 隐藏页面产生的过期 play 拒绝不再把资源永久标坏。
- 同一来源重复渲染不重复读取 IndexedDB 或反复生成 object URL。替换 / 取消 / 销毁会释放不再使用的 URL，异步旧结果不能覆盖新选择。
- 缺失、损坏或不可读的本地资产回退静态封面并提示，不使任务 / 记录页面无法启动。
- 不自动清理已保存原文件，不因另一标签页可能仍在使用而删除旧素材。当前没有完整媒体库清理 / 导出管理器；长期更换媒体可能积累原文件。

### 备份与迁移边界

**业务 JSON 不是完整媒体备份。**

- 身份的静态图 / 动画封面随业务 JSON；动态原文件、视频、字体不包含在其中。外观及背景配置本来就是设备本地偏好，也不随业务 JSON。
- 换设备 / 浏览器后需重新选择原媒体与字体，请自行保留原文件。原引用缺失时使用封面，不声称 JSON 可完整迁移动态素材。
- 业务状态 v4 兼容无版本及 v1/v2/v3，资产引用只接受受限本地 ID；旧程序遇不支持版本只读保护，不要手改版本降级。
- 外观新 key 为 `lime-appearance-v2`；v1 只读迁移，保留旧 key 原始字节，不在启动即覆盖。损坏 / 未来格式阻止普通保存，恢复默认需明确确认。
- 外观跨标签页同步未修改字段，保留本地草稿；快速主题 / 动态开关从最新已保存配置合并单项，不再用旧快照覆盖新背景 / 字体。取消回到最新保存版本。
- Service Worker 只缓存应用运行资源，不把用户 IndexedDB 媒体或第三方 API 响应纳入缓存。

## 4. 外观与字体

- **8 种背景预设**：极光、薄荷、日落、纯净、海雾蓝、暖纸、森林、暮紫；提供可点击色样和明 / 暗对应风格。
- **7 种强调色**：青柠绿、蓝、紫、琥珀、青蓝、玫瑰、石墨。
- **3 种卡片**：磨砂、实色、细边框；保留透明度、面板 / 背景模糊、圆角、密度，新增独立背景遮罩和 90%–120% 全局字号。
- **6 类字体选择**：系统、无衬线、衬线、文字等宽、仅数字等宽、本地 WOFF2。中文缺字回退系统字体，不请求 Google Fonts / 字体 CDN。
- 使用同一外观草稿和保存 / 取消边界，失败不假成功；不是另起一套重复的外观设置。
- 只提供内置模块显隐，隐藏不删除记录，今日任务核心不隐藏；当前没有第三方插件运行时或插件商店。

## 5. 其他工作台参考与插件取舍

本轮阅读了公开官方文档，不冒称运行了第三方私有插件、完成现场逆向或兼容性测试：

- [Homepage Settings](https://gethomepage.dev/configs/settings/)：参考统一调色板、背景亮度 / 滤镜、字体与分组思路，落实为本轮预设 / 遮罩 / 等宽选择。
- [Homarr Media](https://homarr.dev/docs/management/media/)：参考媒体集中管理与权限边界，本轮建立本地 Blob 库及显式格式 / 备份说明。
- [Homarr Custom Widgets](https://homarr.dev/docs/management/custom-widgets/)：服务端请求、受约束模板和独立凭据管理不是当前纯客户端架构已有能力，不能直接搬入并声称安全隔离。

因此本轮**不开放任意 JS / CSS 插件、远程 iframe 或带密钥的插件商店**，也没安装第三方扩展。Dashy 文档抓取过长，本轮未完整阅读，不作为已核实依据。

后续有实际需要再考虑：本地媒体用量 / 导出管理、只读 RSS / 书签导入、受限模板型组件。它们都还未实现；不为堆功能增加重复首页面板。需要服务端凭据的扩展应先设计可信代理与隔离，不把 localStorage Key 交给任意插件。

## 6. API：配置、链路与真实服务分开报告

### AI

- 仍是 **OpenAI chat-completions 兼容协议**，不等于所有厂商原生 API；地址自动解析到 `/chat/completions`。
- 保存不发请求，不再将“有 Key”显示为“已连接”，改为“已配置，未验证”。端点、模型、Key 使用同一验证逻辑。
- “测试连接”使用独立、一次性测试 Key 输入框，**从不回退使用已保存 Key**。确认目标 origin、模型及可能计费后才发送，结束清空测试 Key。
- 仅发送固定合成短句与默认系统角色，不携带工作台记录、摘要或自定义 persona，不执行模型返回动作。
- 公网 HTTPS、精确 loopback HTTP 例外、禁止 URL 凭据 / 查询串 / 片段、`redirect: error`、`credentials: omit`、无 referrer；支持超时、取消、防重入和过期结果作废。
- 配置修改或离开设置取消测试；配置草稿不会被日常重绘覆盖。HTTP 拒绝、错误 JSON、超时、取消、网络 / CORS 不混同为“Key 错误”。

**验证结论：代码与浏览器到本地合成服务的真实 HTTP/CORS 请求通过；真实第三方 AI 服务未验证。** 本轮没有读取或使用用户保存的 Key。服务商账号、模型权限、额度、收费和真实跨域策略，仍需针对明确目标与一次性测试 Key 的单独授权。不得据此写成“所有 API 都可用”。保存 Key 仍是明文 localStorage，不是安全凭据保险箱。

### 天气公开接口

额外运行 `tools/public-weather-check.mjs`，在隔离浏览器使用**固定杭州示例**，不读 GPS / 用户城市 / Key：

- Open-Meteo：固定经纬度调用应用 `fetchWeather()`，实际浏览器请求和当前天气 / 5 日预报解析通过。
- Nominatim：固定“杭州”调用应用 `geocode()`，实际浏览器城市查询及经纬度解析通过。

这是 2026-10-15 当前网络下的两次实际公网请求，不是永久可用性承诺，也不证明真实 GPS 或第三方 AI 可用。天气已获取位置但服务失败时，UI 采用真实错误信息，不再一律误报“没有读取到位置”。

### 明确未覆盖的范围

- 真实付费 / 第三方 AI 账号、模型权限、额度和公网 CORS。
- Safari / iOS / Android 真机、软键盘、原生 WebView，真实 GPS / 系统通知 / 音频必达。
- MP4 实际播放：本轮视频实际证据为 WebM；MP4 签名 / 元数据 / 清理使用单测，codec 仍取决于浏览器。
- 动画 WebP 实际合成器帧变化：本轮已测解析 / 原字节保留，实际像素动画证据来自 GIF，不能混称两者都完成浏览器动画实测。
- 所有主题 × 字体 × 内容 × 尺寸的完整组合、WCAG 认证、长期 IDB 用量 / 浏览器逐出或大型媒体库压力。
- 关页 / 休眠后准点提醒、云同步、完整媒体迁移、第三方插件兼容、公开部署与 native compile。
