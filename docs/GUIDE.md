# 青柠工作台使用指南

> 应用 1.0.0 · Vue 3 + Vite · 业务状态 v6 / 设备外观 v2。本文对应当前界面：固定 Bento 首页、日报站会、休息模式。

## 1. 从浏览器 / PWA 开始

当前首选浏览器 / PWA，不需要先生成 exe 或 APK。需要现代浏览器与 Node.js 22+：

```bash
npm install
npm start
```

打开 <http://127.0.0.1:5173>。持续使用同一个地址：不同协议、域名、端口或浏览器不共享记录。开发模式不注册 Service Worker；`npm run build` 的生产产物才注册离线壳。

Tauri 2 仅保留 Windows / Android 配置，未编译、签名或装机验证，见 [发布指南](PUBLISHING.md)。

## 2. 首页：一眼看到今天

首页是固定 12 列 Bento，不再提供拖拽排序、切换宽窄或模块显隐：

- **主视觉**：日期/问候、今日待办、逾期、专注分钟、工时进度，以及“下一件事 / 下个节点”。
- **NOW**：当前时间与工作时段状态（待上班 / 工作中 / 已下班）。
- **专注表盘**：当前专注倒计时、开始/暂停、今日进度。
- **工作日卡片**：上班时间、距离下班/已下班、「休息一下」「写日报」。
- **下方模块**：今日任务、接下来（提醒）、工作便签、工作链接、本月收支、近 7 天趋势、今日复盘。

手机底部导航为「今天 / 任务 / 专注 / 日报 / 更多」，其余页面从「更多」进入。

## 3. 任务、提醒与日历

- 任务可新增、编辑、改期、完成与删除；今天 / 稍后 / 随时 / 已完成分组。
- 今天包含今天及逾期的已定日期任务；无日期任务在“任务 → 随时”。
- 提醒支持间隔、定点、倒计时与任务提醒；首页「接下来」显示最近节点，日历页管理全部提醒。
- 知悉提醒不等于完成任务；延后 5 分钟不改原周期。
- 提醒依赖页面运行与浏览器权限；关闭页面、节流、休眠或拒绝通知都可能影响触发。

### 排班与工时

- 默认班次在「设置 → 目标」设置上班、下班和午休时间；首页工时进度、工作日卡片和「在岗」提示都会读当天班次。
- 常用班次可存成模板（早班 / 晚班 / 半天），选择日期后一键应用；也可以点模板上的「明天」直接排明天。
- 已排班记录按开始日期覆盖默认班次；当天列表只显示今天及以后，可随时移除。
- 支持跨夜班次，例如 22:00–06:00；凌晨仍按前一天晚上的班次计算在岗与下班。
- 「在岗」分钟数会扣除午休；跨夜时午休可以写 02:00–03:00。
- 当前只支持同一天内的班次（下班时间晚于上班时间）；跨夜班次还不在计算范围内。

## 4. 专注

- 支持 1–180 整数分钟，暂停 / 恢复 / 重置；可关联具体任务。
- 运行中修改目标会先暂停或要求确认；合法旧备份中的更长会话仍保留。
- 到期后只有明确点击“完成关联任务”才完成对应任务。
- 专注记录进入 7 / 30 / 90 天统计与今日复盘。

## 5. 日报 / 站会

侧栏「日报」或快捷键 **D** 打开：

- **今日 / 本周**切换：汇总已完成任务、进行中任务、工作便签和专注分钟。
- 「风险 / 需要协助」可编辑，实时并入摘要。
- 「复制摘要」复制纯文本站会稿，可直接发到群或粘贴到日报工具。
- 摘要只在本地生成，复制前不会发送到任何服务。
- 日报不另存模板；它读取的是任务、专注和便签的当前状态。

## 6. 休息模式

顶栏「休息」、侧栏「休息一下」或快捷键 **R** 打开：

- 3 / 5 / 10 分钟可选，开始、暂停、回到工作。
- 全屏玻璃遮罩 + 呼吸圆环；打开时锁定页面滚动，`Esc` 关闭。
- 到点提示“休息结束，慢慢回来”；休息计时是当前会话，不写入业务记录。

## 7. 记录与生活

- 收支按金额、类型与分类记录；空数据不会用演示数字冒充个人账本。
- 饮水可用快捷量或自定义 1–5000ml；步数是手动填写的**当天总数**，再次输入覆盖。
- 运动记录时长 / 距离，不互相换算；MET 热量只是估算。
- 习惯可自定义、连续天数、近 7 天格子与今日进度。
- 工作便签支持标题/正文搜索；工作链接只接受 HTTP(S)，不抓取远程内容。
- **固定账目模板**：在账本页保存「午餐 ¥25」「通勤 ¥6」等模板，选择日期后一键记入；可设每天 / 工作日 / 每月自动记账。
- 自动记账在打开应用或跨天时补齐当天记录；同一天、同金额、同备注、同分类不会重复记。应用关闭时不会后台运行。
- 今日复盘从已完成任务、专注、饮水、步数与习惯自动汇总，不另存模板。

### 命令中心示例

`Ctrl/Cmd + K` 打开，输入只做本地解析，先看预览再确认。

| 输入 | 确认后的用途 |
|---|---|
| `午饭28块` | 记支出，核对金额和分类 |
| `喝了300水` | 记录 300ml 饮水 |
| `走了6000步` | 覆盖当天总步数 |
| `骑车12公里45分钟` | 记录运动，时长和距离分开 |
| `开始专注45分钟` | 启动 45 分钟专注 |
| `10分钟后提醒我开会` | 确认时起算倒计时 |
| `明天下午三点开会` | 核对日期与时间后添加 |

只输入 `骑行`、`喝水`、`专注`、`提醒` 会给出可点击预填建议，不猜数量或宣称已完成，也不请求 AI。

## 8. 外观与设置

设置分区：**形象 / 外观 / 目标 / AI / 数据**。

- 形象：工作台名称、称呼、头像/文字回退；图片优先，支持常见静态/动画图片。
- 外观：8 种主题预设、7 种强调色、跟随系统/浅色/深色、卡片质感（玻璃 / 纯色 / 细边框）、布局密度、外壳通透度与虚化、背景色彩强度、本地壁纸。
- 目标：上班/下班时间、午休、饮水目标、步数目标、班次模板与未来排班；班次支持跨夜。
- 外观与 AI 配置不进入业务 JSON 备份；业务 JSON 只包含任务、账本、提醒、便签/链接等记录与身份静态图。
- 旧版“独立 Logo / 动态效果开关 / 本地字体 / 模块显隐”已移除；旧布局配置不再读取，但不会删除任务、便签等业务数据。

## 9. 数据、备份与恢复

1. 定期导出 JSON；本机记录不是云备份。
2. 保存失败时先处理提示，不把界面变化当已落盘；多标签页会通过 storage 事件同步，但不是实时协作。
3. 业务状态 v6 兼容无版本号及 v1–v5；非法/超限备份整体拒绝，导入保存成功才切换状态。
4. 外观 v2 只读迁移并保留 v1 原记录；未来格式受只读保护。
5. 清空数据需明确确认，先备份；导入和清空不能依赖撤销恢复。
6. 遇到旧页面先核对 Service Worker / 缓存，不贸然清站点数据。

## 10. 天气与可选 AI

- 天气可手动输入城市，也可主动定位；已保存坐标时开页可能联网刷新。城市/坐标元数据会发给 Open-Meteo / Nominatim。
- 天气服务有额度与署名要求；歧义城市需补省份/国家，不静默猜第一条。
- AI 输入与本地解析不调用模型；只有点击发送才把文字与 Key 发往配置地址。
- 支持 OpenAI chat-completions 兼容协议；公网要求 HTTPS，仅精确 loopback 允许 HTTP。
- Key 明文保存在 localStorage，不是加密密钥库；不要保存生产 secret。
- 保存配置不发请求；连接测试使用一次性测试 Key，不附个人摘要或执行动作。

## 11. 构建与部署

- `npm run build` 输出 `dist/`；只部署 `dist/`，不要部署仓库根目录。
- 推送到 `master` 后 GitHub Actions 执行 `npm ci` → `npm test` → `npm run build` → GitHub Pages。
- 构建产物包含 `index.html`、哈希 JS/CSS、`assets/`、`manifest.webmanifest` 与 `sw.js`。
- Service Worker 需要 HTTPS 或 localhost；修改发布内容时递增 `public/sw.js` 的 `CACHE_VERSION`。
