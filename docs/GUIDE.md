# 青柠工作台使用指南

> 2026-10-17 · 应用 1.0.0 / Vue 3 + Vite · 业务状态 v4 / 设备外观 v2。本文说明当前用法，不是测试通过报告；未测项以本机实际运行结果为准。

## 1. 从浏览器 / PWA 开始

当前首选浏览器 / PWA，不必先生成 exe 或 APK。需要现代浏览器，本机开发与测试使用 Node.js 22+。前端使用 Vue 3 + Vite，需先安装依赖。

```bash
npm install
npm start
```

打开 <http://127.0.0.1:5173>。持续使用同一个地址：不同协议、域名、端口或浏览器不共享记录。直接双击 HTML 不能正常运行 Vue 入口。开发模式不注册 Service Worker；`npm run build` 的生产产物才注册离线壳。开发服务只用于本机，不公开仓库根目录。

HTTPS / localhost 首次联网且完成缓存安装后，页面和本机记录才可离线打开；天气与 AI 仍需联网。安装到桌面受浏览器支持影响，安装不等于获得后台通知。Tauri 2 仅准备 Windows / Android 配置，未编译、签名或装机验证，见 [发布指南](PUBLISHING.md)。

## 2. 今天、计划与记录

- 首页使用 12 列栅格的模块积木：可拖拽排序、切换宽窄、在设置中显隐模块；隐藏不删除记录。窄屏自动单栏并优先任务、专注和提醒，整页滚动。
- 今天包含今天及逾期的已定日期任务；无日期任务在“计划 → 随时”。超过展示数量会提示剩余条数，跳转到对应筛选。
- 任务可新增、编辑、改期、完成与删除。支持的操作提供最近一次全局撤销；不是永久历史，导入和清空不能依赖撤销恢复。
- 便签搜索标题和完整正文，工作链接搜索名称和完整网址；可分批显示与展开长内容。搜索不保存业务记录；搜索期间不能含糊排序。链接只接受 HTTP(S)，不抓取远程内容。
- 收支按金额、类型与分类记录；空数据不会用演示数字冒充个人账本。
- 饮水可用快捷量或自定义 1–5000ml。步数是手动输入的**当天总数**，再次输入覆盖；单次运动独立记录时长 / 距离，不互相换算。MET 热量只是估算。
- 手机底部导航为“今天 / 计划 / 专注 / 日历 / 更多”，其余页面从“更多”进入。响应式检查范围不证明 Safari / iOS 已验收。

### 命令中心实用示例

Ctrl/Cmd + K 打开，输入只做本地解析，先看预览再确认。

| 输入 | 确认后的用途 |
|---|---|
| `午饭28块` | 记支出，核对金额和分类 |
| `喝了300水` | 记录 300ml 饮水 |
| `走了6000步` / `walked 6k steps` | 覆盖当天总步数 |
| `骑车12公里45分钟` / `骑行1小时30分钟` | 记录运动，时长和距离分开 |
| `跑步半小时` / `学习一刻钟` | 记录明确带单位的时长 |
| `开始专注45minutes` | 启动 45 分钟专注，不是补录已完成学习 |
| `10分钟后提醒我开会` | 确认时起算倒计时，不降级为无时刻任务 |
| `明天下午三点开会` | 核对任务日期与时间后添加 |

只输入 `骑行`、`喝水`、`专注`、`提醒`、`开会`、`周报` 会给可点击预填建议，不猜数量或宣称已完成，也不请求 AI。只有距离如 `骑行12公里` 时先预填表单，补齐必填时长才可保存；规则不承诺理解任意自然语言。

## 3. 专注与提醒

- 专注支持 1–180 整数分钟，暂停 / 恢复 / 重置；运行中改目标先暂停或确认。合法旧备份中更长的会话仍保留，不静默裁短。
- 从任务按钮开始专注时按任务 ID 关联，同名任务不混淆；手写目标会解除关联。到期后只有明确点击“完成关联任务”才完成对应任务。
- 提醒中心在全局主内容上方，待处理内容和延后期限持久保存。**知悉不是完成任务**；延后 5 分钟不改原周期或重启专注。
- “日历与提醒 → 定时提醒”可选一次或每天，按本机时区显示下一次时间；已过的每日时刻排到明天。重新打开补显到期内容，不逐次补发每天遗漏的提醒。
- 页面关闭、节流、休眠、权限拒绝或声音策略都可能影响实际触发。Service Worker 不让计时器常驻；当前没有 Web Push，不是脚本 / AI 自动执行器。

## 4. 名称、媒体与外观

- “设置与连接 → 工作台与个人形象”统一预览、保存或取消名称和共享头像 / 标识。
- “问候称呼与独立 Logo（可选）”收纳称呼、文字 / 表情回退与独立 Logo；不是账号登录。切换来源不等于删除另一个已保存素材。
- 头像 / Logo 支持 PNG、JPEG、WebP、GIF / 动画 WebP；动画最大 2 MiB、最长边 1024px。APNG 明确拒绝。
- 壁纸支持图片、GIF / 动画 WebP（8 MiB / 4096px），另支持静音循环 MP4 / WebM（30 MiB、120 秒以内）。浏览器格式支持有差异，失败时保留静态封面，不承诺所有编码均可解码。
- 外观提供 8 种背景预设、7 种强调色、磨砂 / 实色 / 细边框、90%–120% 字号、背景遮罩、透明度 / 模糊 / 圆角 / 密度及本地 WOFF2（5 MiB）；先预览再保存 / 取消，不依赖字体 CDN。
- 动态效果可跟随系统、播放或暂停，顶部按钮可快速暂停；减少动态偏好、页面隐藏或浏览器阻止播放时使用封面 / 暂停。
- 辅助模块隐藏不删除记录，核心任务不能隐藏。工资、发薪日等未接当前面板的字段收在可选旧版兼容设置，不恢复收入面板或新增估算功能；旧跨夜班次数据不能依赖其估算。
- 侧栏 / 标签页名称与图标可更新，但已安装 PWA 的桌面名称和图标不会立即跟随。

### JSON 与媒体不是一份备份

| 内容 | 业务 JSON 是否包含 |
|---|---|
| 任务、账本、提醒、便签 / 链接及其他业务记录 | 是 |
| 身份静态图片 / 动画封面 | 是 |
| 动态图片原文件、视频、字体 Blob（IndexedDB `lime-local-assets`） | **否** |
| 设备外观 v2、背景、旧 `lime-layout-v1`、AI Key | **否** |

换设备、换 origin 或进入原生 WebView 前先导出业务 JSON，并保留媒体 / 字体原文件，在新端重新选择。JSON 导入不是完整媒体迁移；文件选择只存本机，不上传项目或媒体服务器。同 origin 脚本仍可能访问这些资料。

## 5. 天气与可选 AI

### 天气

可手动输城市，不必申请 GPS；主动定位需浏览器授权。已保存坐标时开页可能联网刷新，城市 / 坐标 / 请求元数据会发送给服务。

Open-Meteo 免费档限非商业用途且有额度；Nominatim 公共服务要求全应用限流、标识、缓存与署名。当前客户端去重和节奏限制**不等于跨用户全站限流或跨会话缓存**。歧义城市需补充省份 / 国家，不静默猜第一条。公众规模与商业使用前重新评估，见 [第三方声明](THIRD-PARTY.md)。

### AI

- 输入与本地解析不调用模型；未识别规则也不自动外发。点击“发送给 AI”才将文字与认证 Key 发往展示地址，“附带今天摘要”默认关闭。模型动作需另确认。
- 支持 OpenAI chat-completions 兼容协议，不等于所有厂商原生 API 均可用。公网要求 HTTPS，仅精确 loopback 允许 HTTP；CORS、额度、费用与数据政策取决于服务商。
- Key 明文保存在 localStorage，不是加密密钥库。不要保存生产 secret；前端 `.env` 或安装包常量同样不能保密。取消 / 超时不能撤回可能已接收的请求。
- 保存配置不发请求，显示“已配置，未验证”。连接测试需另填一次性测试 Key，核对地址 / 模型并确认可能计费后才发固定短句，不附个人摘要或执行动作，测试 Key 不回填保存 Key。
- 本地合成 HTTP/CORS 检查不证明真实第三方账号、模型、费用或公网 CORS 可用；**没有真实服务成功结论**，不使用用户保存 Key 取证。

## 6. 保存、清理与恢复

1. 定期导出 JSON；本机记录不是云备份。清站点数据、无痕模式、换端口 / 浏览器或卸载可能丢失记录。
2. 保存失败时先处理提示，不把界面变化当已落盘；多标签页冲突检测不是实时协作。
3. 业务状态 v4 兼容无版本号及 v1/v2/v3。非法 / 超限备份整体拒绝，导入保存成功才切换状态。损坏或未来格式受只读保护，不手改版本降级。
4. 外观 v2 只读迁移并保留 v1 原记录；旧布局值不因功能弃用自动清除。
5. **“仅清理演示数据”不是重置**：只清理可证明演示来源的记录。没有可信来源标记时，未知记录保留、清理数量可为 0，不按常见标题猜删用户数据。真正清空需另行明确确认，先备份。
6. 遇到旧页面先核对 Service Worker / 缓存，不贸然清站点数据。

## 7. 发布、贡献与求职

- 自用先验证任务、专注、提醒与备份；不先填生产 Key。
- 公开源码前检查暂存区、许可、个人资料和密钥；`.gitignore` 不能清理已提交历史。
- `npm run build` 使用 Vite 输出 `dist/`（页面、哈希资源、静态素材、manifest 与 Service Worker）。只托管经核对的 `dist/`，不托管源码根目录。
- [CI](../.github/workflows/ci.yml)使用 Node 22 执行 `npm ci`、单测与 Vite 构建，并核对 `dist` 关键文件；无强制公网 / 浏览器检查或自动部署。本轮未提交、推送、部署或发布。
- 未来托管、商用、备案 / 类目或商店要求因平台与主体而异，本文不是法律 / 合规保证。PWA 也不能直接当微信小程序上传。
- 只写自己真正负责、理解且验证的部分，诚实说明 AI 辅助；不抄测试数量或“生产成熟”口号。
