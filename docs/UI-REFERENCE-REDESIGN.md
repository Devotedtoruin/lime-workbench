# UI 参考与源码交付

本轮：2026-10-16，Web 缓存 v33。保留原生 ES modules、九页模块、业务 v4 / 外观 v2、本地记录与固定自然高度布局。本轮目标是明显改善视觉与信息层级，而不是再做一遍安全审计或添加更多面板。

## v33 实际改动（高级感 / 质感升级）

在 v32 视觉语言重构之上，按逆向同赛道项目（GitHub `Qiang-Z/personal-workbench`，已 clone 到临时目录只读分析其 `app.css` 实测值）+ uweb/优设/pixso 的成熟手法做质感升级，沿用青柠绿品牌色、只借技术不换品牌：

- **品牌质感**：logo 容器与主按钮用品牌渐变 `--brand-grad`（`135deg,#1d5d47→#287259→#3d9b6f`）+ 品牌染色阴影 `--shadow-brand`；品牌名用渐变文字（background-clip:text）；导航激活条改渐变填充 + 光晕。
- **材质层次**：玻璃面板加 1px 顶部内高光 `--panel-edge`（深浅色各一套令牌）；阴影维持双层（扩散 + 紧贴）；焦点态统一品牌光环 `--ring`。
- **排版高级感**：问候标题 32px/800 + 负字距 `-.025em`；eyebrow 改大写字距 `.12em` + 品牌色；数字继续 `tabular-nums`。
- **数据可视化**：新增 `renderSparkline()`，把近 7 天**真实**专注分钟数画成 SVG 渐变面积图（面积纵向渐变 .28→0 + 折线 + 末端锚点）。**数据全为 0 时只画基线，不编造起伏**。
- **图标徽章**：KPI 徽章改渐变底 + 同色光晕（按类别绿/蓝/琥珀/珊瑚/紫五档渐变）。

**保留不变**：青柠绿品牌、8 套主题色、8 套背景预设、深色模式、卡片风格、字号缩放、`appearance.js` 运行时令牌覆盖（`--panel-radius`/`--panel-blur`/`--glass-alpha` 等仍由用户外观设置驱动）、所有 ID/`data-*`/监听/焦点/IME 保证。

**测试**：`sw.test.mjs` 缓存 v31→v33 随发布更新；其余外观断言无需改动即通过。全 527 项单测通过。

## v32 实际改动（视觉语言重构）

前几轮只在既有框架内调整变量，观感几乎不变；根因是 `tests/design-system.test.mjs` 与 `appearance.test.mjs` 把旧外观硬编码成断言（`--panel-radius:12px`、`.stat-tile` 禁止背景/阴影、固定 `--content:1400px` 等），改动一超界测试即红，于是被锁死。本轮连同这些断言一起更新，才真正换了视觉语言：

- **设计令牌**：冷灰蓝画布 `#f4f6fb` 让白卡「浮」出层次；文字三级 `#0f172a`/`#475569`/`#64748b`；主卡片圆角 16px、控件 10px；三级阴影 `--shadow/--shadow-hover/--shadow-float`；Inter 字体栈、数字 `tabular-nums`；缓动统一 `cubic-bezier(.22,.61,.36,1)`，动效 150/200/280ms 三档。保留青柠绿品牌色、8 套主题色、8 套背景预设、深色模式、卡片风格与字号缩放不变。
- **KPI 统计卡**：首页顶部重做为「图标徽章 + 30px/800 等宽数字 + 单位 + 真实进度条」，两张主卡（待办/专注）+ 三张紧凑卡（下班/饮水/步数）单行分主次；不虚构涨跌趋势，只用真实数据。所有 ID、`data-*` 钩子、按钮与可见性语义保留。
- **空状态**：全站统一「虚线框 + 浅灰底 + 居中弱色文案」，0 数据时大数字照常显示，不再是一行灰字的破败态。覆盖今日任务、便签、链接、账本、日程等。
- **动效**：卡片 hover 抬起 2px + 阴影加深 + 边框变深；进度条宽度动画收在 dashboard 作用域，`app.css` 保持无布局属性动画。遵守 reduced-motion 与暂停偏好。
- **测试同步**：`design-system.test.mjs`（圆角/入场时长）、`appearance.test.mjs`（`mini-progress`→`kpi-bar`、整数字号）、`sw.test.mjs`（缓存 v31→v32）随新设计更新；行为、存储、焦点、IME 保证未改。全 527 项单测通过。

## 设计落实

- 明亮、中性的导航与画布，青绿用于主操作／选中／进度；深色有配套表面和边框，而不是一键反色。
- 首页首先回答“今天要做什么”：任务和专注指标优先，工作时间／饮水／步数降为辅助；宽任务区与窄专注／提醒区形成主次。
- 便签与工作链接用紧凑内容行承载，不再反复套边框；原有搜索、编辑、管理、完整内容和余量入口保持。
- 使用一致的标题、正文、辅助字阶与间距；保留中文系统回退、本地 WOFF2 及90%–120%字号。
- 高级外观与字体放在可展开区域，基础主题／卡片／媒体控制仍直接可见；保存／取消继续作用于同一草稿。
- 交互动效只发生在导航／弹层／按钮等明确交互，不因每秒计时渲染重复入场；减少动态／暂停时关闭非必要动效。
- 不伪造增长率、趋势、项目或团队。空态保持真实，可用原有入口添加自己的内容。

## 运行方法

1. 安装 **Node.js 22 或更新版本**。
2. 将整个源码文件夹复制到希望的位置，用终端打开该目录。
3. 运行 `npm start`，保持终端开启。
4. 浏览器打开 **http://127.0.0.1:5173/**。
5. 停止时在终端按 `Ctrl+C`。

无需 `npm install`，不需要 `node_modules`，不能靠双击 HTML 启动 ES modules／Service Worker。已有 Bun 也可运行 `bun tools/dev-server.mjs 5173`。

复制代码不迁移浏览器记录、Key、动态壁纸或字体。沿用相同浏览器和 origin 才能继续看到既有数据；不要为刷新 UI 清站点数据。换设备需自行导出业务 JSON，并另外保留媒体原文件。
