# 青柠工作台 · Lime Workbench

给打工人用的**本地优先工作台**：上班时安排任务、专注、写站会日报；休息时喝水、走动、看身体状态。无需账号，所有记录只保存在当前浏览器。

线上版本：<https://devotedtoruin.github.io/lime-workbench/>

技术栈：Vue 3 + Vite，Web / PWA 优先。`src-tauri/` 保留 Tauri 2 的 Windows / Android 配置，**尚未打包发布**。

## 为什么是“打工人工作台”

不是又一个生活记录 App，而是围绕上班一天的节奏组织：

- **上班前**：今天要做什么、有没有逾期、下一条提醒是什么、今天工作时段。
- **工作中**：快速捕获任务、专注计时、工作便签、常用链接、会议/截止提醒。
- **快下班**：今日完成、进行中、风险和阻塞，一键复制成站会稿。
- **休息时**：3 / 5 / 10 分钟呼吸计时，离开屏幕；喝水、步数、习惯、运动、账本照常记录。

## 界面

- 深色编辑式 Hero + 青柠高光 + 宋体大标题，和浅色工作区形成对比。
- 内容面板使用**渐变玻璃**：高光、模糊、跟随指针的光斑、细边框；外壳保持更厚的玻璃。
- 极光背景缓慢漂移 + 颗粒噪点 + 主视觉光晕；支持 `prefers-reduced-motion` 降级。
- 固定 12 列 Bento 布局：任务 8 列，提醒 / 便签 / 链接 / 账本 / 趋势 / 复盘各 4 列。
- **不再提供拖拽自定义布局**；旧布局配置不再读取，但不会删除任务、便签等业务数据。

## 功能

| 场景 | 能力 |
|---|---|
| 今天 | 今日待办、逾期、专注分钟、工时进度；下一件事、下个节点、实时时钟 |
| 任务 | 新建、编辑、改期、完成、删除；今天 / 稍后 / 随时 / 已完成分组 |
| 专注 | 1–180 分钟，暂停/恢复，可关联任务；7 / 30 / 90 天统计；表盘进度 |
| 日报站会 | 自动汇总今日或本周完成、进行中、便签与专注；填写阻塞项，一键复制站会稿 |
| 休息模式 | 3 / 5 / 10 分钟呼吸计时，全屏玻璃遮罩，到点提醒回到工作 |
| 排班 | 默认班次 + 午休；早班/晚班/半天模板；支持跨夜；一键应用到明天或指定日期 |
| 提醒 | 间隔、定点、倒计时与任务提醒；知悉、延后；日历视图 |
| 工作记录 | 工作便签（含搜索）、常用工作链接、本月收支、7 天趋势、今日复盘 |
| 固定记账 | 午餐/通勤等固定模板，一键记入指定日期；每天/工作日/每月自动记账 |
| 生活记录 | 分类收支、饮水、步数、运动、习惯打卡 |
| 快速录入 | `午饭28块`、`喝了300水`、`10分钟后提醒我开会`，预览确认后写入 |
| 键盘 | `Ctrl/Cmd + K` 命令面板，`N` 新建任务，`F` 专注，`D` 日报，`R` 休息，`?` 快捷键 |
| 个性化 | 工作台名称/头像、主题预设、强调色、明暗外观、卡片质感、密度、玻璃通透度、壁纸 |
| 可选联网 | 手动或定位查天气；OpenAI 兼容 API 只在用户明确发送时请求 |

## 本地运行

需要 Node.js 22+：

```bash
npm install
npm start        # http://127.0.0.1:5173
```

持续使用同一 origin。`localhost` 与 `127.0.0.1` 不共享记录；开发模式不注册 Service Worker。

## 构建与测试

```bash
npm test         # Node Test Runner，383 项业务 / 边界 / 设计系统测试
npm run build    # 输出 dist/
npm run preview  # 预览生产构建，http://127.0.0.1:4173
```

只部署 `dist/`，不要部署仓库根目录。推送到 `master` 后由 GitHub Actions 执行测试、构建并部署 GitHub Pages。

## 项目结构

```text
index.html               Vue 挂载入口与页面说明
src/
  App.vue                Shell、快捷键、弹层挂载
  components/            SideRail / TopBar / 日报休息等组件
  composables/           useWorkbench（状态与持久化）、useWeather
  views/                 今天 / 任务 / 专注 / 日报 / 日历 / 账本 / 习惯 / 运动 / 天气 / 设置
  styles/                base.css（设计令牌）、glass.css（玻璃与动效）
js/                      纯业务逻辑：状态、存储、提醒、专注、账单、天气、媒体、工作区
tests/                   Node 业务、边界与设计系统测试
assets/                  图标与图片素材
public/                  manifest、Service Worker、PWA 图标
tools/                   移动端探测、示例数据截图、原生配置检查
src-tauri/               Tauri 2 配置（未打包发布）
```

`js/` 只放可独立测试的纯逻辑；`src/composables/useWorkbench.js` 把状态接入 Vue 响应式层。

## 数据与隐私

- 没有账号、云同步与跨设备同步；记录保存在 `localStorage`，媒体文件在 IndexedDB。
- 清站点数据、换浏览器/域名/端口都可能丢失记录，需自行导出 JSON 备份。
- AI Key 明文保存在本机，同 origin 脚本可读；不要填入生产凭据。
- 天气与 AI 需要联网；其余功能可离线使用（首次联网完成 Service Worker 缓存后）。
- 提醒依赖页面运行与浏览器权限；关闭页面或系统休眠后不保证准点送达。
- 固定记账的“自动”只在打开应用或跨天时补记当天，不会在关闭页面后后台运行。
- 排班支持跨夜（如 22:00–06:00），按班次开始日期归属；午休会从在岗分钟中扣除。
