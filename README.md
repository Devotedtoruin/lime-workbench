# 青柠工作台 · Lime Workbench

浏览器优先、本地优先的个人工作台，把今天的任务、专注、提醒和生活记录放在一个地方。无需账号或自有后端；核心记录保存在当前设备，天气和用户主动发送的可选 AI 请求需要联网。

**应用 1.0.0 · Vue 3 + Vite · 业务状态 v4 · 设备外观 v2。** 液态玻璃视觉语言、12 列栅格、瀑布流便签、骨架屏与空状态、可折叠悬浮侧边栏，首页支持可拖拽排序的自定义模块。Web / PWA 为主要使用方式；同时提供 Tauri 2 的 Windows 与 Android 打包配置。

## 能做什么

| 场景 | 当前能力 |
|---|---|
| 安排今天 | 任务新建、编辑、改期、完成和删除；今天 / 稍后 / 随时 / 已完成分组，办公便签与工作链接的本地查找 |
| 快速找到 | **Ctrl/Cmd + K 全局搜索**：一个输入框同时检索任务、便签正文、账目、提醒、链接和运动记录，↑↓ 选择、回车直达 |
| 保持专注 | 1–180 分钟自定义计时、暂停与恢复；可按任务 ID 关联，结束后由用户明确选择是否完成任务 |
| 回顾专注 | **专注记录**：7 / 30 / 90 天切换，合计、日均、最长一天、连续天数、环比变化，配柱状图与 8 周热力图 |
| 不漏掉提醒 | 间隔、定点、倒计时及任务提醒；全局提醒中心支持知悉与延后，待处理内容刷新后保留 |
| 记录日常 | 分类收支、饮水、手动当天总步数、单次运动与日历；无记录时显示真实空状态 |
| 坚持习惯 | **习惯打卡**：自定义习惯（名称、图标、每日目标次数），连续天数、近 7 天格子、今日完成进度 |
| 回看一天 | **日历当日回顾**：选中任意一天，自动汇总完成/未完成任务、专注时长、饮水、步数、运动与习惯，全部由已有记录推导 |
| 少填几次表单 | 同一个 Ctrl/Cmd + K 输入框也能用自然语言记录，例如 `午饭28块`、`喝了300水`、`骑行半小时`、`10分钟后提醒我开会`；先预览、确认后写入 |
| 做成自己的工作台 | 工作台名称、个人头像（图片或文字）、称呼；8 种主题预设、7 种强调色、液态玻璃 / 实色 / 细边框卡片、明暗外观、布局密度、玻璃通透度与面板虚化、本地图片壁纸 |
| 自定义首页 | 模块积木可拖拽排序、切换宽窄、按模块显隐；隐藏不删除记录 |
| 按需联网 | 手动城市或授权定位查询天气；可选 OpenAI 兼容 API，输入不自动调用模型，发送与连接测试均需明确操作 |

辅助模块可以隐藏，隐藏不删除内容。工资、发薪日等未接入当前面板的设置仅作为折叠的可选旧版兼容字段保留。

### 使用边界

- 提醒依赖页面运行、浏览器权限与系统状态；关闭页面、后台节流或休眠后**不保证准点送达**。Service Worker 缓存不等于后台推送。
- 步数是手动填写的当天总数，再次填写覆盖；运动记录独立，不自动计步或换算。热量是 MET 估算，不是医学或传感器测量。
- 便签不是完整笔记平台；当前没有账号、云同步、跨模块全文检索、可靠后台服务或健康数据集成。
- PWA 首次联网并完成缓存安装后，才能离线打开已缓存页面与本机记录；天气和 AI 不离线运行。

## 本地运行

需要 Node.js 22+。前端使用 Vue 3 + Vite，需先安装依赖（仅首次）：

```bash
npm install
npm start
```

保持终端开启，停止时按 `Ctrl+C`。打开 <http://127.0.0.1:5173>。生产构建使用 `npm run build`，产物在 `dist/`。

持续使用同一 origin：`localhost`、`127.0.0.1`、不同端口或协议不共享浏览器记录。不要直接双击 HTML。开发模式下不会注册 Service Worker，避免旧缓存干扰；生产构建才注册离线壳。

## 数据、媒体与隐私

- **本地不等于云备份或加密保险箱。** 清站点数据、无痕会话结束、换浏览器 / 域名 / 设备都可能失去记录。定期在“设置与连接 → 数据与备份”导出 JSON；保存失败或多标签页冲突时先处理提示。
- **JSON 不是完整媒体备份。** 业务状态 v4 兼容无版本号及 v1/v2/v3 备份；个人头像与静态壁纸随业务 JSON 保存（已压缩 data URL）。设备外观 v2 与 AI Key 不在业务备份中。换设备需保留并重新选择原文件。
- **未知版本受保护。** 损坏或未来格式不能靠普通保存覆盖；不要手改版本降级，也不要为排查缓存问题贸然清站点数据。旧 `lime-layout-v1` 仅保留兼容保护，当前首页不读写它。
- **AI 由用户明确发送。** 输入只做本地解析，摘要默认不附带；模型写入建议仍需确认。Key 明文保存在本机，同 origin 脚本可读，不保存生产 secret。公网地址要求 HTTPS，浏览器直连受 CORS、额度及服务条款限制。
- **连接测试不是服务保证。** 使用另填的一次性测试 Key，确认目标后才发送固定短句。本地合成 HTTP/CORS 检查不证明真实第三方模型、账号、费用或 CORS 已验证；没有真实服务成功结论。
- **天气可能开页联网。** 保存坐标后可能自动刷新；城市、坐标与请求元数据会发送给天气 / 地理编码服务。公共服务有用途、额度与署名要求，公众规模使用需另评估。

完整操作说明见 [使用指南](docs/GUIDE.md)。

## 测试与公开分发

```bash
npm test
npm run build
```

- `npm test` 使用 Node Test Runner，不需要真实天气 / AI 服务；覆盖业务状态、提醒、专注、账本、外观、命令解析与工作区记录，并包含 Vue 设计系统与形象/美化设置的静态断言。单测不等于浏览器验收、覆盖率证明或生产认证。
- `npm run build` 使用 Vite 输出 `dist/`：`index.html`、哈希命名的 JS/CSS、`assets/` 静态素材、`manifest.webmanifest` 与 `sw.js`。只部署 `dist/`，不部署仓库根目录。
- CI 使用 Node 22 执行 `npm ci`、单测与生产构建，并检查 `dist` 中的关键文件；仅有 `contents: read` 权限，没有自动部署。
- 开发验证脚本位于 `tools/`：`mobile-probe.mjs` 用 CDP 模拟 390px 视口检查横向溢出，`seed-probe.mjs` 写入示例数据并截取桌面 / 移动端截图，`check-native.mjs` 只读检查 Tauri 配置。

Web 部署与桌面 / 移动打包步骤见 [构建与发布](docs/PUBLISHING.md)。

## 项目结构

```text
index.html               Vue 挂载入口
src/                     Vue 3 单文件组件、组合式状态层与设计令牌
  App.vue / main.js
  components/            SideRail、TopBar、CommandPalette、TaskDialog 等
  composables/           useWorkbench（状态与持久化）、useWeather
  views/                 今天、计划、专注、日历、账本、习惯、运动、天气、设置
  styles/                base.css（设计令牌）、glass.css（液态玻璃与组件）
js/                      纯业务逻辑：core、state、storage、reminders、focus、agent、weather、workspace 等
sw.js / manifest.webmanifest
assets/                  应用与第三方素材
tests/                   Node 业务、边界与设计系统测试
tools/                   移动端探测、截图种子与原生配置检查
src-tauri/               Tauri 2 / Rust 打包配置，未原生编译
docs/                    使用指南、第三方声明与发布说明
```

业务状态、事务存储、计时、命令解析、外观与本地媒体仍分别由 `js/` 中的纯模块管理；`src/composables/useWorkbench.js` 只负责把它们接入 Vue 响应式层，浏览器记录格式与旧版完全兼容。
